🌐 Portafolio Personal – Edwin Murillo

Este es mi portafolio personal desarrollado con Astro y Tailwind CSS, donde presento mis proyectos, habilidades y experiencia como desarrollador web.

El objetivo de este sitio es mostrar de forma clara y rápida quién soy, qué hago y en qué tecnologías trabajo.

🚀 Tecnologías utilizadas

Astro – Framework principal para sitios estáticos rápidos y optimizados

Tailwind CSS – Framework de estilos utility-first

Node.js 22+

npm – Gestor de dependencias

📂 Estructura del proyecto
src/
│── components/     # Componentes reutilizables
│── layouts/        # Layouts base del sitio
│── pages/          # Rutas del sitio (file-based routing)
│── styles/         # Estilos globales (Tailwind)
│── assets/         # Imágenes y recursos


Astro utiliza file-based routing, por lo que cada archivo dentro de pages representa una ruta del sitio.

🧩 Secciones del portafolio

Home – Presentación principal

Sobre mí – Perfil profesional y stack tecnológico

Proyectos – Proyectos destacados con enlaces a GitHub y demo

Contacto – Formas de contacto y redes profesionales

⚙️ Instalación y uso

Clona el repositorio:

git clone https:/github.com//Smith-Muri
cd tu-repositorio


Instala dependencias:

npm install


Inicia el servidor de desarrollo:

npm run dev


Abre en el navegador:

http://localhost:4321

🏗️ Build para producción
npm run build
